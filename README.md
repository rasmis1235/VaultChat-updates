# VaultChat updates

Signed Android APKs of VaultChat, used by the app's built-in updater (`latest.json` on the latest release). This repository holds no source code.

**Only install APKs signed with this certificate** (SHA-256):
`1a867d0debe9c5a6cbfa3e17aa968247ed4007d387cd127b41186caf5687417a`

Check with: `apksigner verify --print-certs VaultChat-<version>.apk`
